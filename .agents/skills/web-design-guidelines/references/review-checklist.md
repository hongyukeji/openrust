# Web 审查清单

改写自 [Vercel 固定版本规则](https://github.com/vercel-labs/web-interface-guidelines/blob/434b7f91364665f2f733b310ec54809bf8f37937/command.md)，许可见 [LICENSE](../LICENSE)。按目标页面选择条目；不将所有条目强加给每个组件。

## 语义与焦点

- 动作用按钮、导航用链接；图标按钮有可访问名称，控件有 label，表格有对应表头。
- 保留可见焦点与合理 Tab 顺序；弹层打开、关闭和路由切换后焦点可预测，遮罩关闭后不残留焦点陷阱。
- 错误关联对应字段，异步反馈能被辅助技术感知；图片按内容提供 alt，装饰图标不制造重复朗读。
- 保留缩放、键盘操作与手势替代入口；固定页头和底栏不遮挡焦点或内容。

## 表单与反馈

- 合理的 type、inputmode、autocomplete 与 name；允许粘贴密码和验证码。自动填充策略按字段语义决定。
- 区分必填、格式错误、服务端拒绝、网络故障；提交后可定位首个错误，并保留安全的输入。
- 请求处理中阻止重复动作；未保存离开、危险操作按实际后果提供确认或撤销。
- 登录失效、无权限与空数据分别呈现，敏感字段不出现在错误、控制台或截图中。

## 内容、导航与显示

- 可分享的筛选、排序与分页合理映射 URL，敏感值不进入 URL；返回和刷新恢复有契约。
- 时间、数字与文案使用应用国际化配置；不将浏览器语言覆盖用户已选语言。
- 长名称、中文、翻译膨胀、空数组、极大数字、窄屏与缩放不隐藏必需信息或操作。
- 使用设计 token 检查文字、控件与焦点对比度，主题切换后原生控件也可读。
- 图片占位防止布局跳变；重要内容的加载优先级与实际可见性一致。

## 性能与动态效果

- 尊重减少动态效果偏好；避免影响操作的长动画与不受控循环。
- 大列表按测量结果采用服务端分页或虚拟化；虚拟化同时验证键盘和辅助技术可用性。
- 输入、筛选和表格更新有合理响应时间，过期请求不覆盖新结果。
- 页面卸载后释放监听器、定时器和连接；用测量证明优化效果。

这是项目维护的适配清单，不宣称完整 WCAG 合规，也不替代真实浏览器和辅助技术验证。
