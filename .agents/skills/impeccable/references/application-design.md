# 后台与移动应用设计规则

改编自固定上游快照的 `reference/operate.md`、`harden.md`、`layout.md`、`polish.md`；已按 OpenRust 改写。来源版本与许可见 [技能入口](../SKILL.md)。

## 信息与布局

- 用页面标题、当前位置、工具栏与主内容建立任务顺序；同类操作在不同页面使用相同位置、命名和状态。
- 将相关信息相邻放置，不靠多层卡片表达每一级关系。列表保留完成任务必需的列，低频细节渐进展开。
- 响应式要明确侧栏折叠、工具栏换行、表格滚动或移动摘要、弹层尺寸。不能用隐藏全页横向溢出来掩盖被截断的操作。
- App 以触摸、返回路径、安全区域、软键盘及前后台切换为设计输入；不把浏览器悬停作为唯一操作入口。

## 视觉系统

- 使用语义化颜色和间距 token；选中、只读、禁用、失败和成功的含义跨页面一致，状态不只依赖颜色。
- 字体与数值列服务于扫读，允许系统字体；数字对齐、时间与单位表达一致。中文和长翻译用实际内容检查，不机械套用英文行长或字号比例。
- 已选组件库有合适能力时直接复用。新增 token 或组件需要明确的重复职责，不为每个页面建立抽象。
- 动效解释展开、切换和反馈，尊重减少动态效果设置；常用后台操作不等待装饰性入场动画。

## 状态与恢复

| 场景 | 应表达与验证的内容 |
| --- | --- |
| 初次加载与刷新 | 保持布局稳定，区分旧数据、更新中与加载失败 |
| 空列表与无搜索结果 | 区分尚无数据、筛选无结果、无访问权；只提供有权限的下一步 |
| 表单失败 | 字段错误可定位，保留可安全保留的输入，避免泄漏密码或令牌 |
| 慢请求与重复提交 | 呈现处理中状态；超时不等于服务器未执行，不盲目重试非幂等写入 |
| 权限或身份变化 | 区分登录失效与访问被拒绝，按认证契约刷新或重新登录 |
| 并发更新 | 避免静默覆盖，显示冲突及恢复路径；乐观更新失败时可回退 |
| 长文本与大数据 | 保留查看完整信息的方式；按规模选择分页或虚拟化并测量 |

验证整个操作路径后再微调像素：先修任务阻塞、错误信息和不可访问操作，再修层级、布局与视觉偏差。只清理本次引入的无用样式与临时素材。
