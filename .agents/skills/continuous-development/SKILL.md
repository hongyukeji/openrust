# 持续开发

用户说“持续开发直到完成”“中途自动恢复”等即为本任务守护授权，不要求用户输入技能名、命令或线程ID。仅登记明确获准的完整任务，不把授权扩展到其他对话、产品或发布。

## 启用与恢复

1. 核对仓库规则、Git/WIP、todo/plan及当前目标。检查原生 `get_goal`：未建目标时按用户授权创建；已有未完成目标沿用，不缩小目标或擅改预算。新的独立任务须先处理目标范围冲突，不能覆盖旧目标。
2. 在仓库根运行 `python3 -B .agents/project/scripts/controller-recovery.py start`。自动读取可信 `PASEO_AGENT_ID`、`CODEX_THREAD_ID`，查本机线程索引校验仓库及主线程。已运行则复用，不为子代理另开守护。目标明确指定另一对话时使用已核实的 `--agent` / `--thread`，不得猜最新对话。
3. 用同脚本 `status` 核对监督进程存活和目标身份，再继续工作。发送已入队不等于已恢复；要有新轮次/工具执行证据。已派发的任务先收件，不重复创建写入者。

守护使用标准库，正常接续仍由原生Goal负责；错误与遗漏接续由外部进程处理。网络/限流三次失败后进入冷却监测并本机通知，不永久退出；额度自然重置后复核再恢复。权限、认证和真实外部阻塞保持待处理并通知，不绕过授权。普通编码/测试连续失败仍遵守AGENTS.md，继续其他独立任务。

## 完成与停止

- 整体目标完成前核对获准计划、当前待办、实际验证和提交证据；单簇提交、worker完成或一句总结不能代替验收。满足后 `update_goal(status="complete")`，守护会自动回收自己创建的监督/工作进程、协议与CLI子进程及PID记录。
- 用户明确说“停止持续开发”“结束自动执行”时，先执行 `python3 -B .agents/project/scripts/controller-recovery.py stop --stop-task`，持久禁止唤醒、暂停原Goal并中断主控；收取并中断该主控自己派发的在途子代理，核实进程停止。不得停止他人的Agent、Cargo任务或基础服务。只想停止守护时使用 `stop`，不停止正在开发的主控。
- 中间提问、查询进度、修正任务不是停止授权。界面取消/Goal暂停优先，守护不得覆盖；后续明确“恢复持续开发”时重新执行启用流程。

运行状态/配置/精简日志留在忽略的 `storage/controller-recovery/<agent>/` 供审计，不含凭据或完整对话。空锁文件保留inode但释放锁，避免并发启动竞态。守护不安装系统服务；电脑重启或监督进程本身被终止后须再次触发启用，不能宣称永不中断。具体机制见[持续交付](../../project/plans/laravel-rebuild-execution.md#整计划执行守护)。

守护回归入口：`python3 -B -m unittest discover -s .agents/project/scripts -p "test_controller_recovery.py" -v`。测试只用隔离CLI和临时任务，不向真实开发对话发送或停止。
