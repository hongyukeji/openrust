# 后台流程验收矩阵

OpenRust 项目补充。按当前功能簇选择用例，不因技能被读取就执行所有管理操作；只使用隔离测试账号、数据和已授权环境。

| 流程 | 关键行为 | 证据 |
| --- | --- | --- |
| 登录、刷新、退出 | 正确/错误凭据、并发刷新、失效处理、退出后状态清理 | 页面与真实认证响应；复用当前 token 撤销时限 |
| 菜单与权限 | 刷新/直达 URL、隐藏按钮、角色变化、越权请求 | 页面状态及 API 拒绝；隐藏按钮不是授权证据 |
| 列表查询 | 筛选、排序、分页、清空、返回恢复、请求乱序 | 请求参数与结果、重载后的 URL/状态 |
| 表单 | 客户端/服务端校验、重复点击、失败保留输入、更新冲突 | 请求次数、持久化结果与错误反馈 |
| 上传下载 | 大小/类型限制、取消、失败恢复、私有文件访问 | 真实存储与授权结果，不只模拟 URL |
| 异步任务 | 接收、处理中、失败、重试与取消 | 页面与任务实际状态；不将入队当执行完成 |
| 通知与实时连接 | 重连、退出、权限变化、页面卸载 | 投递结果、连接与监听器释放；集群能力另按拓扑验收 |
| 国际化与交互 | 支持语言、长文本、窄屏、缩放、键盘、弹层焦点 | 实际操作与截图，注明未测浏览器/辅助技术 |

默认不通过真实短信、邮件或破坏性业务数据制造用例。涉及对外发送时仍按已有目标与凭据授权执行；缺失条件明确列为未验收。
