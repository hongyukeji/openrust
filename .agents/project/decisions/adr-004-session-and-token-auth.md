# ADR-004 认证默认为 Cookie 会话与个人访问令牌

- 状态：Accepted
- 日期：2026-10-25

## 背景

框架同时面向浏览器端应用与 API 服务。无状态 JWT 难以即时撤销与审计，不适合作为唯一默认。

## 决策

- 提供两种 Guard：`SessionGuard`（Cookie 会话，数据库 store 默认，配合表单时启用 CSRF）与 `TokenGuard`（个人访问令牌，存储 SHA-256 哈希，支持前缀、能力列表、过期时间）。
- 密码哈希 Argon2id，参数可配置并带安全默认值；登录、注册、密码重置端点默认限流。
- 内置流程：注册、登录、登出、密码重置、邮箱验证；授权用 `Policy` + 最小角色权限模型。
- JWT 不在第一代；作为 0.2 候选 `auth-jwt` feature。DataScope 与多租户不在第一代。

## 影响

- `openrust-auth` 依赖 `openrust-mail`，因此邮件能力提前到 M3。
- 用户表结构由迁移定义，业务通过追加迁移扩展字段，不继承框架结构体。
