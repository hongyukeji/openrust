# ADR-011 v1 版本短信与邮件通信能力

- 状态：Accepted（M4 队列通知已实现；短信 API / Twilio adapter 见 [ADR-033](adr-033-sms-driver-and-template-contract.md)，账户实发仍需授权验收）
- 日期：2026-10-25

## 背景

应用开发常需要邮件与短信，只有注册登录接口而缺少可使用、可测试、可替换供应商的通信能力，不能满足创建项目后直接进入业务开发的目标。短信纳入 v1 版本；邮件保留既定 v1 版本范围。

## 决策

- 在 M3 增加短信能力，与邮件采用独立的公共入口和供应商适配边界，遵循 [ADR-009](adr-009-extensible-capability-drivers.md)。框架内置常用实现，开发者可通过公开契约扩展自己的供应商，无需修改框架。
- 短信提供发送入口、模板标识与参数、供应商错误映射及超时配置；v1 版本至少有一个真实供应商适配，以及本地开发 log 与测试 fake 实现。当前选用 Twilio Messaging REST，比较与实现边界见 ADR-033；不预先承诺全部厂商。
- 邮件保留 SMTP、log、fake、纯文本与邮件模板，以及本地 Mailpit 路径。M4 接入队列后，为邮件与短信补充异步发送及失败处理。
- 外部发送实现通过可选依赖或 feature 接入，配置缺失时给出可操作错误；本地开发默认不需要短信账户或产生发送费用。生产环境不得悄悄回退到 log/fake 并报告真实发送成功。
- 明确供应商接受请求与最终送达的区别，不把返回发送请求成功描述为用户已收到。若供应商支持回执，扩展契约需允许适配；v1 版本是否内置回执端点按具体供应商 contract 决定。
- 超时结果可能不确定；队列重试需说明重复发送风险，按供应商能力使用幂等标识，不承诺恰好一次发送。
- 密钥、验证码与完整消息内容不进入生产日志；收件号码/地址按需要脱敏。log/fake 驱动的内容捕获仅用于明确的本地或测试场景。
- v1 版本通信验收包含真实供应商接入证据、本地不付费路径、公共契约测试、错误映射与队列重试边界。真实发送必须具有明确的目标号码/地址及费用授权；没有凭据或授权时记录未完成项，不以 fake 测试代替实发验收。
- “开箱即用”指本地无需购买账户即可运行和测试，生产填写有效凭据与模板配置即可接入；不表示框架能免除供应商账户、模板审核或发送费用。
- 薄多渠道通知编排按 [v1 覆盖计划](../plans/v1-capability-coverage.md) 接入，复用邮件/短信/队列；业务通知中心和站内信 UI 归 [v2 后台套件](../plans/v2-admin-platform.md) 核心，移动推送供应商归 v2 评估候选。
- M4 通知任务由 `Notifier` 分渠道派发；业务数据与多个渠道任务需原子提交时必须使用数据库事务 API。队列至少执行一次，provider 接受但 worker 未确认时可能重复发送；通知内容持久化于队列表，不构成发送历史或站内信记录。

## 需要补充评估的完整使用路径

以下是设计检查项和建议；验证码机制已纳入 v1 设计，具体方案见 [补强计划](../plans/v1-performance-and-readiness.md)，其他项仍先复用现有规划，发现缺口后再确定范围。

| 场景 | 需要核对的闭环 |
| --- | --- |
| 注册与账号找回 | 认证、邮件/短信发送、凭据验证、过期与撤销、失败响应是否能完整跑通 |
| 验证码 | 通用 API 与数据库存储按 [ADR-026](adr-026-generic-verification-codes.md) 实现方向落地；目的/身份绑定、有效期、原子一次消费、尝试次数和重发冷却属于服务职责。Mail/SMS 只负责发送，不默认启用短信登录或修改账号模型 |
| 异步通信 | 模板渲染、队列投递、失败查询、重试和重复发送风险是否有明确行为 |
| 上传与下载 | 核对既有存储能力是否有大小/类型限制、访问授权和可测试示例，不等于新增媒体平台 |
| 外部服务调用 | 评估统一出站 HTTP 超时、错误处理和测试替身是否有必要；非幂等请求不自动重试 |
| 安全与运维 | 核对会话/CSRF、限流、密钥遮蔽、健康/就绪检查和诊断命令，区分已有规划与新增缺口 |
| 扩展开发 | 官方实现和独立第三方适配能否通过相同公开入口注册，并运行契约测试 |

## 影响与执行

- v1 版本计划移除“短信不纳入”，M3 增加短信，M4 增加队列化短信；更新 [框架设计](../plans/framework-design.md) 与 [roadmap](../roadmap.md) 保持范围一致。
- M3 已以 ADR-033 补充能力命名、配置、Twilio adapter 与验收 contract；无需新增运行时依赖。
- 按当前任务队列逐簇闭环，代码、生成器、配置示例、测试与模块事实同步更新，设计决定不能替代实现证据。
