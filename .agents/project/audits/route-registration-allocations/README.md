# 路由注册分配热点与字面路径优化

2026-11-24。用户要求解释128条GET路由的13700次分配，安全优化并保持注册顺序和既有行为。固定代码基线为 `e03be8accee84131133a1eecac7b8609d23c834c`；隔离副本只叠加本批生产实现和消费者，不混入其他协作者的在途代码。

## 定位结果

相同Release分配计数器、相同128条16字节URI，重新得到13700次alloc、3471次realloc，说明不是上一轮计数器或长度推导引入的假象。

| 差分测点 | 128条的alloc | realloc | 累计请求字节 |
| --- | ---: | ---: | ---: |
| 完整Router创建、GET注册及销毁 | 13700 | 3471 | 2826604 |
| 仅完整RoutePattern::compile及销毁 | 12800 | 3328 | 2651264 |
| 正则表达式准备、RegexBuilder编译及销毁对照 | 12672 | 3328 | 2631552 |

原先**每条没有任何参数的字面路径仍独立编译正则**。完整路径编译每条约100次alloc，合计占完整注册的93.43%。正则准备／编译对照覆盖其中大部分；它是差分子流程测量，不是分配调用栈，不能把不同测点数值再相加。其余约900次来自URI、方法列表、handler、路由和索引等已有登记工作，本批不重排这些流程。

## 实现与保留

生产变更限定在 `vendor/openrust/framework/src/routing/route_pattern.rs`：

- 增加持有`Box<str>`的字面匹配器。无参数且不超过1024字节的有效路径，以完整字符串比较替代正则；仍使用原有字面字符验证。
- 正则匹配器私有字段更名为`matcher`，反映其新增实现。没有新增公开入口、配置或全局缓存。
- 参数捕获、可选参数、绑定字段、PCRE约束及域名继续用原来的引擎，域名大小写规则不动。
- 1024只是内部优化边界，不是新路径长度限制。更长模板走原有正则流程，保留原有编译资源限制及错误。1024／1025／4096／512KiB均与既有正则构建结果对照。
- 字面路径参数结果继续通过原`parameter_values`生成，保留静态路由默认参数。
- `Router::insert_route`、方法索引、注册覆盖、域名优先级及缓存序列化都未修改。避免另加“静态路由优先”的索引而改变先注册的动态路由行为。

曾检查复用现有URI槽位的表示，但没有降低实际分配／字节，最终保留直接持有字面值的表示，保持规范化URI槽位的原有语义。新增枚举变体允许编译器改变私有对象布局；不承诺动态路由对象尺寸完全相同。按上述差分合计，本批非路径编译部分累计请求字节略有变化，但静态注册总体请求字节和峰值显著下降。

实现参考本地固定PHP对照环境中的Symfony `Matcher/Dumper/CompiledUrlMatcherTrait.php` 的静态路径分支（SHA见结果摘要），并核对`v0.x`的Axum路由登记：旧版将匹配交给Axum／其静态路径索引，不能直接拷贝为当前自有Router。采用的是“字面路径不必编译正则”的成熟机制，当前框架原有登记与选择顺序保持。没有复制第三方代码，也没有调整默认路由或中间件组。

## Release对比

Apple M4 Max、Rust 1.94.0，`cargo build --release --locked`，两组都开启`CARGO_PROFILE_RELEASE_INCREMENTAL=true`，其余Release默认；同一路径、同一代码基线、相同URI与handler。计时使用默认分配器，计数使用另一个System包装二进制；无计数器计时。argv0统一为`registration-perf`，31对随机交错样本，10000次配对bootstrap。计数每组5次，结果完全可重复。私有测点只放在隔离副本，不进入生产提交。

最终实际执行79项Rust测试（框架HTTP／路由42、根应用startup／console／resource_generator37），0失败、0忽略；workspace格式及根应用／框架all-targets严格Clippy通过。真实主二进制另通过19项CLI、6项HTTP检查：134个命令无重名，首页／HEAD、健康、JSON／HTML404均正常，SIGINT退出0，直接执行`./artisan inspire`成功。默认HTTP独立验收使用array Session／Cache并关闭其他Runner，未将它计为队列和调度发布验收。

一次最终检查因32GB磁盘守卫中断；其他构建在忙时没有强行清理其缓存，空间恢复后从相同源码重跑。中断不计通过。保留`gates-interrupted.log`等原始记录。

## 证据与复验

- 原始记录、两组二进制、临时源码和完整命令：`target/tmp/route-registration/`；`base.json`固定基线，`gates.py`保存实际检查命令，`compiled-probes/`保存已编译的诊断消费者。
- 本目录`results.json`保存前后计数、统计、关键源SHA、二进制SHA及最终验收结果；`measure.py`和三个`probe_*.rs`保存实际测量逻辑。
- 两个额外临时静态测点均在隔离Router中：`__profile_pattern`仅编译并black_box一个RoutePattern；`__profile_regex`编译`format!(r"\A{}\z", regex::escape(uri))`，使用相同dotall RegexBuilder。两组一致，正式检查前移除这些适配器及examples。
- 复测现有独立二进制可在根目录运行：`python3 -B tests/build_guard.py --workflow route-registration --target-dir target/tmp/array-release/cargo-target -- python3 -B .agents/project/audits/route-registration-allocations/measure.py`。用`ROUTE_PERF_DIR`选择项目`target/tmp/`内的独立数据目录，目录下须包含相同布局的before／after二进制；脚本会写入该目录，不覆盖其他任务。
- 本批没有改CLI、缓存格式、公开路由API和三语用法；纯内部优化无需改变开发者代码。临时适配器和注册脚本没有写入生产源码。其他协作者的工作区／索引保留，仅本地提交，不推送。
