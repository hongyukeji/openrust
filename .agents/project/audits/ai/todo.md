# E07 剩余任务

实施顺序、固定基线和范围以 [E07 开发计划](../../plans/laravel-ai-sdk.md#实施顺序与完成条件)为准。SDK 与网关的验收证据分别记入 [SDK 账本](README.md)和[网关账本](gateway.md)。本清单的编号用于跟踪任务。

- 每批依原计划开发并验收。每项通过后单独勾选，并链接对应证据。每批验收通过后单独本地提交，不推送。
- 涉及基线候选入口的条目先核对适用平台和已审定范围。验明支持条件或拒绝行为后记录裁决，涉及计划范围调整时先取得用户确认。
- 供应商实机单列。本地协议模拟证据可关闭本地验收项。缺账号、地区、模型权限或正式报表的实机项保持未勾选，记录所缺条件。
- 已验收的 `vendor/` 迁移、会话和审批附件私有 Storage、跨进程审批恢复及 xAI 转录时长与脱敏费用保留原证据。xAI 转录计费的本地三库验收提交为 `d0a3954d6`，正式费用见 E09。
- OpenRust 自有 AI HTTP 接口及路由前缀按计划暂缓。网关保留 `/v1/usage` 和自有账务入口，旧 Sub2API 专用计费路由的移除见[验收记录](gateway.md#gw-05-sub2api-专用计费入口移除)。
