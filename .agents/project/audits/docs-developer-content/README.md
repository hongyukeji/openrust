# 开发者文档内容边界整理

日期：2026-11-20。

## 对文档受众的理解

`docs/` 的读者是使用 OpenRust 构建应用的开发者。正文回答如何安装、配置、调用和排错，明确当前支持限制；兼容版本、协议要求、所有权及语言适配等影响使用的信息应保留。贡献指南可以介绍贡献流程，应用测试指南可以说明公开测试接口。

开发计划、内部任务编号、交付批次、代理交接、测试执行经过、环境流水、待验矩阵、源码对账与性能声明审核属于项目内部材料。将它们迁到 `.agents/project/` 对应职责目录；混合段落先保留可操作的用法与限制，再迁出过程记录。迁出历史原文不是重新验收，也不代表当前功能状态。
