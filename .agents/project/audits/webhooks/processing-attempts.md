# Webhook 接收处理尝试记录

本批落实 WD-04 的接收尝试记录和旧 token 写回边界。复用[固定 Laravel 的 Worker 语义](https://github.com/laravel/docs/blob/960eedf0911155ad16326ade49c0ea5d18eda0b8/queues.md)及现有原生数据库、队列和租约。一次领域领取对应一个接收 ID 与持久代次。领取事务同时推进代次、更新租约并创建尝试行。接续过期租约时，上一代未结束的尝试在同一事务标记为过期。完成、释放、延期、失败和停止均使尝试与接收状态在同一事务落库。尝试状态按该行 token 条件写回，业务处理器在事务外执行。尝试只保存代次、时间与固定分类，随接收记录删除。

测试在隔离数据库使用真实 HTTP 和独立 Artisan Worker。真实进程崩溃后另启 Worker，观察旧代次从运行中变为过期，新代次独立完成。另以测试专用 SQL 把旧租约置为过期，保持原 Worker 存活并让新进程先完成。放行旧进程的迟到业务失败，核对最新接收记录仍完成且没有新增异常，两个尝试的状态保持过期及完成。复核主动释放以及延期、永久失败、普通失败和截止的尝试历史。

隔离源码以 `4f19d7c29` 加本任务已验提交至 `586f9b52e` 和本批文件为基线，使用 Rust 1.94.0 与项目 build_guard。日志保留于 `target/tmp/webhooks-attempts`。租约续期、尝试管理公开入口、恢复扫描、外部 broker 和跨主机、发送侧领取、真实供应商均保留后续门禁。WD-04 与 WH-03 整体保持开放。

SQLite、PostgreSQL 18.7、MySQL 8.4.13 每库通过 158 个真实 HTTP 请求和 107 次独立 Artisan Worker，包括本批新增 1 个 HTTP 与 3 次 Worker。三库迁移、回滚五个扩展迁移后重新迁移、旧记录读取通过。旧接收和签名回归、许可、全仓格式、启用两 Webhook feature 的 workspace/all-targets 严格 Clippy 通过。同步三语文档与六个示例复编译，三语站点构建、根／子目录浏览器与导航通过。站点保留既有块体积提示。本批隔离数据库和站点输出已清理。
