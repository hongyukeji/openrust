# Webhook 出站端点与当前版本许可

## 应用契约

`DeliveryStore::endpoints()` 提供按投递范围隔离的 `EndpointStore`。应用授权后可创建、查找、替换、暂停、恢复和删除具名端点。变更使用预期配置版本，URL 或签名凭据引用变更时产生新版本。暂停和恢复沿用原版本。删除保留禁用记录及名称归属。公开的 `WebhookCall::use_endpoint` 将当前版本绑定到不可变发送快照，登记时拒绝跨范围绑定、过期版本或绕开已选凭据。保留直接指定 URL 的现有发送方式。新绑定使用快照的可选字段，旧快照仍可由新版读取。启用绑定前将生产者和消费者更新到支持该字段的版本。

已绑定的投递在领取事务、实际请求前和结果写回时复核端点。暂停时原待处理记录保留截止时间。如果在领取后、实际请求前发现暂停，则解除租约并归还该次额度。定时扫描在唤醒窗口内跳过已暂停端点。已过期记录不能因恢复获得新尝试。删除、无法找到端点或版本不符时，执行态转为取消。已经发出的请求仍可能在接收端执行，真实响应保留在当次尝试记录。当前许可也应用于历史重放。借鉴 Svix 删除或禁用后阻止发送的做法，版本匹配及短事务规则沿用项目 WD-03。[Svix 固定 Worker](https://github.com/svix/svix-webhooks/blob/931467b95a1bbcc520c47bcb96f4e436782abcd2/server/svix-server/src/worker.rs) · [Svix 重试说明](https://docs.svix.com/retries)

端点表仅保存凭据引用。运行时还走应用的投递授权与凭据解析、固定目标地址和 TLS 验证，避免把端点管理授权视为无条件网络许可。管理命令只在验收应用中注册。生产应用通过自身授权入口调用公开服务。

## 实际验收

在隔离源码叠加 Webhook 历史至 `3f4176eff` 与本批文件，Rust 1.94.0。SQLite、PostgreSQL 18.7、MySQL 8.4.13 实测 HTTP、Artisan 和 Worker。覆盖端点重复登记、状态过期操作、暂停后原队列 Job、扫描跳过、过期后恢复、旧版本取消、新版本实际签名、跨范围及覆盖凭据拒绝、领取后发送前暂停返还额度、在途请求收到 204 后仍保持取消、删除后无法原名复活、人工重放当前许可和迁移回滚保护。SQLite 普通出站、重放及接收回归通过，接收包含 136 个实际 HTTP 和 83 次独立 Worker。八个包测试、三语六组编译示例、全仓格式及双特性 workspace/all-targets 严格 Clippy 通过。日志在 `target/tmp/webhooks-endpoints/`。

后续继续共享限额、有界订阅扇出、凭据修订与迁移治理，以及状态查询和正式部署验收。WH-04 至 WH-07 仍按账本逐项推进。
