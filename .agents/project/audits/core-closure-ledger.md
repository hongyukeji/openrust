## 05-01 模型生命周期

SQLite 和 MySQL 8.4 已验证模型持久化、读取和软删除事件，以及静默和取消。显式事务写入、提交和回滚已用 SQLite／MySQL 验收，为事务后 Observer 提供执行边界。事件映射已用 SQLite 和 MySQL 8.4 验证取消写入、普通监听器回退、事务提交与回滚。模型复制及静默复制已通过 SQLite 和 MySQL 8.4 验证。自动 UUIDv7、ULID 及复制和路由绑定已在 SQLite 和 MySQL 8.4 验收。数据库生成列刷新已在 SQLite 和 MySQL 8.4 验证。单模型写连接回读、原位刷新、命名关系重载和事务锁定回读已通过双库验收。MySQL 行锁在提交和回滚时的释放已实测。05-01 核心闭合。 [验收](05-01/README.md#模型生命周期派发)

## 05-02 关系身份筛选

四个关系身份 OR 变体、多态 Pivot 身份查询、中间表过滤、插入默认值、排序及时间戳已通过 SQLite 和 MySQL 8.4 验收。自定义 Pivot 的类型化水合、转换、写入生命周期与多态隔离已专项验收。Pivot 反向关系自动水合已通过双库验收，MySQL 核对无额外查询。多对多切换及声明端触碰已专项验收。模型保存时的 `BelongsTo` 和 `MorphTo` 所属关系触碰及递归传播已通过双库验收。Pivot 变更时的相关端触碰已通过双库验收。常规模型保存时可声明普通和多态多对多触碰，已通过双库验收。Pivot 写入可从模型正反向声明推断触碰。应用作用域的动态关系登记、解析及加载已通过双库验收。动态关系的存在、缺失和计数查询已通过双库验收。组合模型可显式登记动态关系回退。点分关系路径的批量预加载已通过双库验收。已登记单目标关系支持点分路径存在、缺失及末级计数。已登记的多目标 MorphTo 路径加载、存在、缺失和计数已通过双库验收。多态路径可从数据库发现实际目标。普通和多态路径可批量补齐缺失后代。从集合借用单模型时，可按自动预加载策略批量加载根集合的关系。已加载集合支持单键、批量和模型主键查找及缺键错误，也支持按模型身份和谓词判断包含关系。集合可批量合并可见性设置及替换、清除追加字段。集合支持模型映射、Support 集合转换、带键映射及投影。带键模型映射可保留 Eloquent 接口，显式键随刷新、转换和 JSON 输出保留。借用单个关联模型时，首次访问下一层缺失关系可回到根集合批量加载并写回关系图。多态目标借用可按选定别名批量加载并回写根集合。借用可沿多层普通和多态关系回到根集合。移出集合的根模型可共享首层关系批量查询，通过异步关系访问取得的后代可继续共享批量查询。批量加载后的关系立即对同批模型的同步读取及序列化可见。集合支持按键分区、分组计数和重复项检测。集合支持位置配对、双向填充和模型扁平转换。位置配对支持多输入，标量键投影可与原集合键交换。集合支持读取队列元数据和共有关系路径。普通模型与集合可通过类型化 JSON 标识从真实 Worker 恢复，任务级缺失模型的默认失败、可选静默删除、锁释放及批次重放已验收，自定义普通与多态 Pivot 可从 Worker 恢复，并保持原表写入约束。集合公开主键字典。普通和多态关系支持类型化列筛选、缺失与 OR 入口，普通关系可共用筛选及预加载条件。已登记路径支持末级列条件、闭包、缺失、OR 与条件预加载。多态通配路径的末级筛选与预加载共用实际发现的目标，已通过双库验收。集合可在刷新时按多个已登记路径预加载，已通过双库验收。多态延后计数与聚合已写回父模型的关系缓存，通过双库验收。多态关系与登记路径的延后重载也已写回父模型缓存，通过双库验收。声明端可按目标叠加预加载、计数与约束，通过双库验收。多态目标的三个软删除加载选项、混合目标和约束顺序已通过双库验收。PHP 任意属性的对象共享及隐式类继承继续跟踪。 [验收](05-02/README.md#带键的-eloquent-集合)
