# AI SDK 可选扩展：对标 Laravel 官方

> 标识：`ai`；定位为阶段二的可选通用扩展。
> 状态：已授权开发，已排入唯一todo的阶段二待领取队列；尚未实现或验收。当前C04-D1先闭环，本项按前置与队列领取，不抢占进行中的核心功能簇。

## 目标与范围

将Laravel官方AI SDK作为本扩展唯一主要对标，以固定源码/版本逐项实现Rust对应能力，而不只做审核/翻译接口。功能、概念、命名、配置、默认行为、Provider生命周期、扩展与测试方式按官方实现；Rust类型/所有权/async必要适配须记录约束、等价行为和验证。Prism仅用于交叉参考，不引入与官方不同的第二套SDK或优先级。不能直接运行PHP扩展，Rust侧复用成熟组件并完成官方语义整合，不只复刻链式方法名。

开发者通过统一SDK选择在线服务或独立自建模型服务；2核4GB、4核8GB应用节点无需承担模型推理。关键词规则、文本/图片审核及翻译是SDK之上的场景封装和唯一模块示例，须复用官方对应Agent/结构化输出/分类等机制，不另建平行AI体系。目标是提高业务效率与降低总成本，不承诺零成本、零误判或完全替代人工。

| 能力 | 交付边界 |
| --- | --- |
| 关键词过滤 | 词库、规范化及高效匹配，支持命中位置与替换；规则优先，不为确定性匹配引入模型。词库来源/许可证与更新策略明确，保留原文位置映射 |
| 文本语义审核 | 专用分类小模型或经评估的在线模型识别广告、辱骂等类别；类别、语言、阈值和效果随模型版本声明，不笼统承诺所有敏感内容 |
| 图片审核 | 专用图像分类小模型或支持图像的在线模型评估声明的内容类别；先支持经验证的静态图片，不把图片分类等同 OCR、视频审核或全语义理解 |
| 机器翻译 | 专用翻译模型或经评估的在线模型，显式源/目标语言、长度限制与术语/格式支持范围；只承诺验收过的语言方向，不以模型名代替质量证明 |
| 业务处置 | 输出命中项、类别分数及可选策略建议，由业务决定放行、拒绝或复核；人工流程/第三方补充通过公开接口组合，不内置运营后台 |

本扩展不替代i18n翻译文件、复数及语言回退；用户内容翻译沿SDK调用。官方SDK的Agent、工具、会话、文本/结构化/流式输出、图像、语音、转录、摘要、Embeddings、Reranking、Classification、Files/Vector Stores、用量、故障转移、事件与测试等，凡固定基线包含的适用能力，均须在AI-0逐项盘点，不因首个业务场景用不到就删减。官方SDK提供的MCP工具调用须与独立MCP扩展协调契约与依赖，不能用“互不前置”豁免已承诺的SDK行为。

SDK通用接口不等于框架内置聊天产品、运营后台、训练/微调平台、自造向量数据库或AI模型平台；业务产品仍需单独授权。SDK也不等于框架必须内嵌推理引擎。额外OCR/视频等非固定官方SDK能力先独立评估，不能借SDK对标无限扩张。

## 本地、在线与混合模式

| 模式 | 使用方式 | 依赖边界 |
| --- | --- | --- |
| 自建模型服务 | 通过HTTP连接本机或另一台服务器上独立运行的模型服务 | 应用只需客户端；模型服务另行部署和验收，不内嵌推理引擎 |
| 内嵌本地推理（后置评估） | 在应用方进程内加载经验证的轻量模型 | 仅通过AI-5质量/资源/成本门槛后提供可选后端；不属于首批必交 |
| 在线 | 硬件不足或更重视模型效果时，显式选择服务商连接 | 复用现HTTP Client及远程driver，不要求安装本地引擎/权重 |
| 混合 | 按任务分别指定连接，例如关键词本地、语义或图片审核在线；可显式配置本地失败/不确定时的远程后备 | 不自动跨模式外发；后备条件、允许外发的数据和费用上限明确配置 |

- 优先实现DeepSeek、阿里云千问（Qwen）、OpenAI、Anthropic Claude的适用适配；这只是实施顺序，不是官方SDK对标范围上限，其余固定基线provider进入AI-0矩阵按依赖补齐；具体模型/区域、文本/图像输入、结构化输出及任务质量逐项验收，不承诺每家都支持全部任务。缺少对应能力在配置校验/调用时明确报不支持，不静默换模型。审核分类器分数与生成模型自报分数不得视为等价概率。
- Laravel式默认/命名connection绑定任务；审核与翻译业务接口保持一致，任务可显式选择连接。相似接口协议只复用真正共同的HTTP部分，不能把“兼容OpenAI格式”当作跨厂商完整兼容；鉴权、schema、错误与限流保留适配。
- 服务商Key、受控endpoint与模型从既有config/.env读取，日志脱敏；管理员设置复用既定加密及受权动态设置契约，不引入新密钥体系。连接/凭据重建按现资源刷新契约处理，不承诺改配置即安全热切。
- 远程请求采用有界并发、超时、限流和重试，遵守服务商返回的退避信息；响应校验失败、拒答、额度不足及内容不受支持均有明确语义。重复付费风险与任务幂等分别说明，不承诺网络超时重试不会重复计费；统计已报告的用量及适用调用上限，缺失用量不伪造为零。
- 缓存/结果包含实际provider、模型revision、提示/策略版本与语言，远程输出同样视为不可信数据；审核和翻译结果不能直接执行。第三方调用需要开发者提供有效账号、凭据与授权测试内容，缺条件保留未验收；不自动注册、充值或发起付费测试。

## 普通服务器与交付优先级

以2核4GB、4核8GB、无GPU的普通应用服务器为目标，实施顺序优先官方SDK在线模型驱动、轻量词库及场景示例，再接自建模型服务HTTP接口；不要求安装本地引擎或在应用服务器运行模型。模型服务可部署在其他有算力的机器上，不必增加所有应用节点的规格。调用API不会消除业务并发/网络/缓存的资源消耗，仍须按实际负载验收。

| 工作负载 | 2核4GB | 4核8GB |
| --- | --- | --- |
| 词库规则与在线接口 | 首批优先路径 | 首批优先路径 |
| 连接独立模型服务 | 客户端接入，不据此保证同机服务性能 | 同左；服务端单独计算资源 |
| 进程内专用分类小模型 | 不作默认生产承诺，后置评估 | 可评测低并发候选，达标才交付 |
| 同机生成式翻译/聊天模型 | 不作为常规部署方案 | 不作为与主业务共享资源的常规方案 |

这是工程选型与验收方向，不是性能测试结果。同机DB/Redis/应用资源须先扣除，不能将服务器总内存当作模型可用内存。在线接入先闭环，再评估内嵌：质量、峰值内存、线程/CPU、P95延迟及主业务影响和总成本均达到预定标准才引入；不达标就暂不内置，保留公开driver接口及评测缺口，不以加载成功宣称生产可用。内嵌后端不是首批扩展交付或V1完成的强制前置。

## Laravel 风格接入与架构

- 使用现有ServiceProvider/Container及官方AI SDK对应的领域config/.env、默认provider/model和公开driver契约；命名连接只在官方对应机制内适配，不自创与官方冲突的默认值。业务通过同一SDK及可选场景封装调用，不直接操纵张量、第三方 eventloop或各厂商请求格式。Facade 若提供，与 DI 共用服务，不另建全局推理体系。
- SDK公开契约先对照官方源码/测试确定，场景封装依托对应官方机制。模型分词、预处理、推理及输出解释封装在适配器内；审核/翻译的业务输出不得冒充官方统一SDK协议。AI-0用真实开发流程收敛API及Rust必要适配，本计划中的描述性名称不构成已实现API。
- 外部开发者能注册自己的模型/driver，不修改框架 src；框架提供结果与错误边界，业务模块复用应用服务。沿现有上传扩展、验证、事件、Queue、Cache、Storage接入，不另造上传/任务/审核工作流引擎。
- 未显式配置模型连接时不发起模型调用，词库可独立使用；不因低分、超时或模型缺失自动外发数据。在线模式无需先尝试本地；混合后备须业务显式配置并授权。付费调用、计量和数据外发单独说明。
- 模型输出是评估结果。分数不直接当作校准概率；`uncertain`/不支持类别或语言明确返回。缺模型、超限、繁忙、超时和推理失败返回类型化错误，不能默认为审核通过；待复核状态与服务故障分别表达，处置策略由业务显式选择。

## 运行与资源边界

1. **真正可选**：未选择对应 Cargo依赖/feature，不编译专属推理/图像依赖、不注册对应服务、不加载权重、不创建推理线程或访问网络；remote-only不编译本地推理专属依赖；文本、图片、翻译按实际构建成本隔离，不能选择文本就拉全部图像模型。最终 feature/package 拆分在选型后最小化确定，Cargo.lock 解析影响与默认构建隔离分开验收。
2. **成熟组件**：AI-5进入内嵌评估时首选验证 ONNX Runtime + Rust `ort`，Candle 为模型适配或部署约束下的备选，不默认集成两个引擎。内嵌评估核对具体版本、MSRV、许可证、算子/模型格式、量化、目标CPU及原生库打包；第一方保持 forbid(unsafe_code)，不要求生产主机安装 Python、训练环境、GPU 或自动安装系统软件。
3. **有界运行**：Provider 注册/校验不立即加载权重；已配置任务首次使用或显式预热时加载并复用。推理使用受限执行资源与并发闸门，不阻塞 Tokio 工作线程；同时限制引擎内部线程、排队长度、输入大小和输出量，避免每个 session 自建满核线程池。取消等待不等于已停止 CPU 推理，须验证原生调用截止/取消与关闭边界，不在取消后无界释放并发名额。
4. **同步与队列**：轻量请求可同步，图片/长文本/批量翻译优先复用现有数据库队列和独立 worker 运行角色。队列载荷存受权对象引用，不塞大型原始图片；重试有界，结果幂等。审核前公开发布、异步 pending 的可见性与租户访问由业务策略约束，示例不能先公开再审核。
5. **模型资产**：清单保存模型ID、不可变revision、任务/语言/类别、分词及预处理版本、格式、许可证、来源和校验值；权重与原生运行库作为明确部署资产，不放 Git、Cargo target 或默认应用安装包。安装/更新由显式操作或部署流水线完成，离线运行不偷偷下载或加载任意远程代码；应用缺资产明确报错。不执行模型包携带的脚本/自定义算子插件，额外格式须评估后显式纳入。
6. **升级与多节点**：首批采用固定模型版本与滚动重启，不承诺权重热替换。节点报告已加载版本，队列任务/缓存键携带模型和策略版本；跨版本结果不混用，旧任务版本不可用明确失败/待处理。共享DB持久化配置、任务和必要结果，Redis仅可选缓存；每节点权重需随部署迁移或从固定制品源校验恢复，不能承诺只迁DB就自动恢复模型文件。
7. **隐私和成本**：日志/指标默认只记模型版本、状态、耗时与资源，不记原始文本/图片；结果缓存按租户隔离，包含内容摘要、语言、模型/词库/策略版本并设置TTL，原文/译文缓存显式受控。图片解码限制字节数、像素、帧数与格式；默认接收受权存储对象，不让模型自由抓取URL。内容与译文不作为可执行命令，展示时沿业务转义规则。

管理员未来可在既定受权动态设置机制交付后通过该机制修改明确允许的阈值、词库或已安装可信清单内的模型选择，配置版本与审计复用现机制；模型文件加载和切换的生效方式须单独声明，首批不可热换的变更标记待重启。框架不提供强制后台或固定管理路由，也不为本扩展新建动态配置系统。

## 实施顺序与验收

阶段二在 Provider/配置/扩展契约、存储/上传及适用安全基础具备后启动；队列子项另依赖 Queue 已收口。不依赖AI模型平台或可选快速开发模块；普通模型调用无需MCP Server，官方SDK中MCP工具子项按其自身真实前置另验收。已进入唯一todo的阶段二开发队列；前置满足后从AI-0开始按Spec→Implement→Verify→Commit逐簇领取，不能继续停留为仅规划或另建平行队列。不抢占当前核心功能簇，未领取前不宣称已开工。

| 顺序 | 工作 | 验收要求 |
| --- | --- | --- |
| AI-0 统一接口与 Spec | 锁定Laravel官方AI SDK源码commit/版本、文档及测试，建立全部适用能力映射；Prism只补充参考；收敛Provider/配置和Rust公开API | 逐项官方源码/测试→RustAPI/config→行为测试→示例/生成项目/文档→真实provider证据；覆盖安全/错误/默认/扩展/生命周期；不以难度或业务暂不用标不适用，不自行升级框架内核基线；不将内嵌选型作为SDK前置 |
| AI-1 SDK基础与在线接入 | 按官方配置/Provider、Agent/提示/文本/结构化/流式输出、工具/会话及测试机制分子簇实现，适用四家远程驱动 | 未选择扩展无专属依赖/网络；在线或自建服务模式不引入本地推理依赖；公开consumer可替换，词库命中/Unicode边界有测试 |
| AI-2 官方能力及场景 | 按AI-0矩阵补官方其余适用SDK能力；词库、审核与翻译沿官方机制封装，复用缓存/队列/上传 | 每家按能力实际验收；独立语料测误报/漏报、语言质量与结构化输出，不用模型自评代替；租户/缓存版本隔离、pending可见性、429和付费重试边界明确 |
| AI-3 自建模型服务接入 | HTTP连接本机或独立服务器上已部署的模型服务，例如Ollama；保持统一业务接口 | 真实服务端到端验证已声明任务/模型、能力差异、鉴权、超时和关闭；连接成功不代表同机推理达标，不自动安装/启动服务或拉取模型 |
| AI-4 首批交付 | 唯一modules/example、生成项目、README/config和普通服务器部署 | 固定官方SDK全部适用项逐项闭环，明确缺口不虚报1:1；在线/自建服务/显式混合策略真实互操作、构建依赖隔离；2核4GB与4核8GB代表环境记录HTTP P95/内存/吞吐（注明CPU与同机服务）；公开API、生成应用check/test与适用门禁，不用mock冒充供应商或自建服务验收 |
| AI-5 内嵌推理后置评估 | 首批闭环后再测专用文本/图片分类及适用翻译候选，按真实价值选择引擎 | 固定权重/格式/许可证/量化/CPU及语料；同机资源、质量、P95和总成本均达标后才交付可选后端，并补完整公开调用/示例/部署验收；否则记录暂不内置及证据，不强行集成ONNX/Candle，也不虚报已实现 |

资源与成本测试必须同时观察普通HTTP请求的P95、引擎线程和worker进程总内存；同机应用/DB/Redis的资源预算单列。报告词库/模型各命中比例、人工复核率与第三方调用减少量，比较新增计算、维护及模型升级成本；不预填未经实测的节省比例或吞吐。

## 选型来源与当前限制

主要参考 [Laravel官方AI SDK](https://laravel.com/docs/13.x/ai-sdk) 的统一Provider、配置、结构化输出、队列与测试体验；[Prism](https://prismphp.com/getting-started/introduction/)补充链式调用与多Provider体验。实施Spec锁定对应源码和版本，不因参照新版SDK修改内核固定Laravel基线。内嵌选型仅参考 [ONNX Runtime 执行后端](https://onnxruntime.ai/docs/execution-providers/)、[ort](https://github.com/pykeio/ort)、[Candle](https://github.com/huggingface/candle) 的成熟推理能力；仅作选型输入，远程SDK/模型基线在AI-0锁定，内嵌引擎/权重在AI-5单独锁定。没有新增Cargo依赖、下载权重、执行推理或修改框架代码；远程服务商为用户指定的计划接入对象，API/模型基线和真实调用条件须在AI-0核对。本轮未调用任何服务商；目前没有质量、性能、模型商业使用或平台兼容性验收结论。
