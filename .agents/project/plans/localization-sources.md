# 统一国际化与数据库语言来源

状态：真人已授权开发；实现、负责人和验收状态仅在[唯一待办](../todo.md)维护。本计划不代表功能已交付。

## 交付契约

- 易用性约束：基础文件翻译开箱可用；调用方始终使用统一翻译入口，切换或组合来源不修改业务翻译调用。未指定语言自动采用配置默认值，常用场景仅配置必要选项。
- 扩展性约束：通过固定 Laravel 对应的公开 Loader／Provider 契约替换或组合来源，不为每种来源增加独立业务 API；只提供实际需要的扩展点，不预建通用插件平台或假设性抽象。
- 复杂度约束：数据库、缓存刷新及跨实例通知按需启用；文件模式不要求数据库、Redis、后台进程或管理界面。默认行为明确，配置集中；高级策略不能增加普通翻译的必需步骤。

- 复用唯一 `Translator`、消息目录、语言作用域和 Provider；对照固定 Laravel `Translation\Loader`、Translator 和 FileLoader 的公开扩展契约，不建立第二套数据库翻译服务。
- 未指定语言时使用配置的 `default_locale`；显式语言及请求协商共用统一选择规则。缺少翻译按统一语言回退规则处理，不在错误渲染分支硬编码英文，不擅自把当前默认语言改为中文。
- 文件来源保持默认；数据库来源为显式选配，可单独使用或组合使用。翻译调用方无需区分来源。实现前明确组合优先级、缺失键与空字符串、命名空间和 JSON 键的行为。
- 用户可见框架错误、验证、默认 JSON、HTML 和 API 封装均复用同一翻译机制；稳定错误码、状态码、协议字段和内部诊断不翻译，5xx 继续隐藏敏感来源。
- 数据库适配复用现有 Db、迁移和 Cache 公开机制。定义批量加载、缓存、显式刷新及更新／删除的一致性边界；不在每次同步翻译时阻塞查库，不新增永久刷新进程或管理后台。
- 初始化顺序与数据库不可用必须有明确、安全且可观测的处理，避免数据库错误依赖尚未就绪的翻译服务。回退不能泄露 SQL／凭据，也不能冒称数据库来源加载成功。

## 实施与验收

### 已批准的数据库来源策略

借鉴 OpenSpring 的数据库覆盖、快照与提交后失效经验，公开接口和默认仍以固定 Laravel Loader／Provider 为准，不移植 Java 实现或引入第二套翻译体系。

- 文件默认模式不要求数据库连接。显式组合模式中，同一语言候选下数据库中存在的有效条目优先于文件；缺失条目继续查文件，随后按统一语言回退顺序处理。精确来源与语言回退顺序须写入公开配置与契约测试，不能让默认语言数据库条目意外遮蔽已指定语言的文件条目。
- 缺失、禁用和空字符串分别定义；不因参考实现使用空白过滤而擅自丢弃合法空翻译。原子发布同一修订的不可变消息快照，避免读到混合更新或删除后旧条目残留。
- 框架管理的文案变更与修订号在同一事务中提交；仅在提交成功后失效本节点缓存并通过既有可选事件／共享通知机制通知其他节点，回滚不发布新修订。
- 多实例采用通知加有界修订核对间隔兜底；间隔可配置，不硬编码移植 OpenSpring 的五秒默认。广播丢失、乱序、重复及共享通知不可用时仍能收敛，明确这是最终一致而非全节点即时同步。直接外部 SQL 修改需按公开契约推进修订或显式刷新，不能承诺自动发现未登记写入。
- 数据库故障按显式策略回退到已验证快照或文件／安全默认资源；暴露脱敏诊断和恢复状态，控制重试频率，避免错误渲染再次访问故障数据库形成递归。
- 管理后台不作为本簇前置；提供框架公开加载／刷新能力和唯一模块调用，管理界面继续遵循既有业务范围边界。

沿现有 Localization 范围去重，关联已安排的 I18N-E01 错误渲染整改；按可独立交付边界分簇，不扩大当前 DB／CLI 冻结候选。核心公共契约、迁移与集成由总控负责，具体实现安排互斥并行负责人。

先完成实现、配置、唯一模块的实际调用、配套测试代码及文档，再交独立测试对话，在 `openrust-dev` 验证：

- 文件默认、数据库独立来源、组合覆盖与命名空间隔离。
- 默认语言分别配置为中文与英文且未指定语言、显式语言、缺失键回退及空翻译。
- 参数、复数／选择、刷新后的更新与删除、并发语言隔离及后台默认语言。
- 同一语言数据库覆盖文件、指定语言优先于其他语言回退、空值与禁用条目、事务回滚不失效、提交后失效、多实例通知丢失／乱序及修订兜底收敛。
- 默认 JSON／HTML／API 封装、验证消息、5xx 脱敏及数据库不可用。
- 受影响 MySQL、PostgreSQL、SQLite 实际生产链路、生成应用和适用组合门禁；未运行的后端与场景单列缺口。
