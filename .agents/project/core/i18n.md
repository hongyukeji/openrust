# `openrust::translation`

> 受众：AI Agent
> 更新：2026-10-26
> 摘要：请求级国际化当前事实；contract 见 历史决策 032。

## 实现

- `Locale` 规范化常见 BCP 47 language/region/script 标签；`TranslationConfig` 由唯一 ConfigRepository 的临时 `i18n` 配置区提供，根可编辑 `config/i18n.rs` 与显式配置来源复用同一 Provider 生命周期。该配置权威与 Laravel `app.locale`/`app.fallback_locale` 的差距仍须整改。
- `MessageCatalog` 内置英文与简体中文框架消息；应用可通过 JSON 字符串、`insert`、`insert_plural` 或 `insert_select` 合并/覆盖 locale 下的消息。普通字符串和 `{name}` 插值保持兼容；structured JSON 可声明 ICU/CLDR 类别 `plural` 或有限值 `select`，`other` 必须存在，缺参选 `other` 并保留原占位符，缺失 key 原样返回。命中语言回退资源时，plural 规则按资源自身 locale 计算。
- `Translator::format_number` 接受精确十进制字符串并按 locale 处理数字符号、分组及小数符号；`format_date` 接受公历日期，`format_datetime` 接受 Chrono `DateTime<Tz>` 并格式化其本地字段。调用方负责先按业务选定的时区转换 instant；框架不读进程默认时区、不改变 API/存储数值或 UTC 时间。ICU4X 编译数据覆盖其提供的 locale 数据范围。
- `TranslationServiceProvider` 安装不可变 `Translator` service。HTTP response-context middleware 从 `Accept-Language` 按 q 值与受支持资源选择 locale；默认语言由 `[i18n].default_locale` 配置。配置 fallback 用于当前 locale 缺少消息键时查找最后资源。
- 请求语言存于 Tokio task-local，不是进程级可变状态。`RequestLocale` 可提取当前选择；`Translator::with_locale` 为认证后的用户偏好或后台任务建立显式覆盖作用域。
- 中英文资源覆盖框架 `ApiResponse` 成功消息、标准框架错误和内建 validator rule code。稳定 error `code`、HTTP status 与 validation field path 不变；未提供翻译的 application `Custom` 错误保留原展示文本，所有 5xx 仍隐藏来源。
- 邮件/短信内容由应用在 compose 前用共享 `Translator` catalog 生成；请求邮件使用 `RequestLocale`，后台消息显式选择 `Locale`。`LocalizedEmail`、SMS log/fake/Twilio driver 已实现，传输层不自行推断语言；SMS provider template 仍由供应商渲染，详见 [通信事实](mail.md)。

## 边界

不提供 Fluent 语法、模板代码执行、精确数值分支、自动 Session 用户偏好读取、自动邮件/SMS 发送 locale、HTML 转义或完整 Accept-Language 浏览器质量范围解释。应用负责资源装载和模板输出上下文转义。`*` 请求语言退回应用默认语言。

## 验收

- 6 项 i18n 单测覆盖 canonicalization、q 值排序、无效标签、JSON resource、覆盖、参数和 fallback、并发隔离、TOML section。
- `tests/server/i18n/runtime.rs` 覆盖同一 router 并发中英错误消息、validator rule 本地化、code/path 稳定、未知 application error 保留原文、request locale、显式 locale 覆盖和应用 JSON resource 的 HTTP 调用。
- 新生成项目 `/tmp/openrust-i18n-generated-20261026` 的 `cargo check` / `cargo test` 通过；真实进程请求带 `Accept-Language: zh-CN` 的不存在路径返回 `code=not_found` 与 `请求的资源不存在`。
- 全工作区 default/all-features fmt/clippy/test、warnings-denied docs 和 `cargo deny check` 通过。详见 `memory/testing.md` 与 `memory/verification.md`。

F2 国际化复数/选择与数字/日期地区格式化已实现；HTTP、邮件、短信与后台任务通过同一 `Translator` / `MessageCatalog` 显式选择 locale。gRPC 接入后复用同一服务并纳入对应专项验收。

## 显式来源

应用安装器在默认 Provider 列表末尾、package 注册前选择文件来源或显式 Loader 工厂；提前解析与启动后复用同一 Translator。普通译器保留 Laravel 查找策略，错误、验证及需要空值/全局 JSON 回退的调用显式选择共享目录的 Catalog 视图。

刷新单航班在同一绝对期限与取消上下文内构建并校验新快照，再原子发布；捕获失败保留旧快照，并在 Loader 结果析构前发布本轮失败状态。文件来源使用有界、安全打开；Windows 原子文件边界尚未实测。
