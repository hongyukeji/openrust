# openrust-events

Events for the [OpenRust](https://github.com/hongyukeji/openrust) framework (milestone M4). Planned surface: `Event` trait, listener registration via `app.listen::<E, L>()`, synchronous dispatch and `queued` listeners that run through `openrust-queue`.

**Status:** scaffold only. Scope and contracts are defined in the framework design; implementation lands in its milestone.
