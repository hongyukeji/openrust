# openrust-auth

Authentication and authorization for the [OpenRust](https://github.com/hongyukeji/openrust) framework (milestone M3). Planned surface: user table conventions, Argon2id hashing, `SessionGuard` and `TokenGuard`, `CurrentUser` / `OptionalUser` extractors, `Policy` trait, minimal roles and permissions, register / login / logout / password reset / email verification flows and the `user:create` command.

**Status:** scaffold only. Scope and contracts are defined in the framework design; implementation lands in its milestone.
