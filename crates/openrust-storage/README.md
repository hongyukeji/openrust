# openrust-storage

Storage for the [OpenRust](https://github.com/hongyukeji/openrust) framework (milestone M5). Planned surface: `Storage` service with named disks, `put` / `get` / `delete` / `url` / `temporary_url`, local filesystem default and S3-compatible backends (feature `storage-s3`), plus `FakeStorage` assertions.

**Status:** scaffold only. Scope and contracts are defined in the framework design; implementation lands in its milestone.
