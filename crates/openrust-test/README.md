# openrust-test

Testing toolkit for [OpenRust](https://github.com/hongyukeji/openrust) applications (milestones M2-M5). Planned surface: `TestApp::boot()`, chainable response assertions (`assert_status`, `assert_json_path`, `assert_problem`), per-test database isolation, `Factory` helpers and fake-driver assertions for queue, mail and storage.

**Status:** scaffold only. Scope and contracts are defined in the framework design; implementation lands in its milestone.
