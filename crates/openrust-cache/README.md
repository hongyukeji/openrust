# openrust-cache

Cache for the [OpenRust](https://github.com/hongyukeji/openrust) framework (milestone M5). Planned surface: `Cache` service with `get` / `put` / `forget` / `remember` / `increment`, drivers `MemoryCache` (moka, default) and `RedisCache` (feature `cache-redis`).

**Status:** scaffold only. Scope and contracts are defined in the framework design; implementation lands in its milestone.
