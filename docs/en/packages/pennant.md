# Pennant

## Support status {#support-status}

**Not included in this source line.** No Pennant feature-flag store, feature resolver or pennant command is shipped. Cargo features select compiled dependencies; they do not provide per-user runtime feature flags.

This chapter retains the Laravel navigation path for comparison. Its presence does not install a package or promise compatibility with the corresponding PHP API.

## Available entry points {#available-entry-points}

See [Configuration](../getting-started/configuration.md) for the native interfaces and usage. When integrating a separate library or service, implement the application adapter and validate its lifecycle, errors and credentials against that service's contract.

## Scope {#scope}

OpenRust does not provide an installation command for this integration. Do not copy a Laravel Composer or Artisan command into OpenRust on the assumption that this navigation entry implements it.
